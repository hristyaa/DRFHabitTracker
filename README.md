# Habit Tracker

## Описание:
**DRFHabitTracker** - это backend-приложение для отслеживания полезных привычек с системой напоминаний через Telegram-bot.
Проект реализован на Django REST Framework и поддерживает отложенные задачи через Celery.

## Функциональность проекта
**Модель «Привычка»**

Привычка описывается по формуле: «Я буду [действие] в [время] в [место]»

#### Поля модели:
- Пользователь — владелец привычки
- Место — где выполняется привычка
- Время — когда выполняется
- Действие — конкретное действие
- Признак приятной привычки — определяет тип привычки
- Связанная привычка — используется для полезных привычек
- Периодичность — частота выполнения (по умолчанию ежедневно)
- Вознаграждение — поощрение за выполнение
- Время выполнения — не более 120 секунд
- Признак публичности — возможность публикации привычки

#### Типы привычек:

Полезная привычка — основное действие, которое пользователь выполняет.
Приятная привычка — используется как награда за полезную привычку.
Приятная привычка может быть связана с полезной.
Одновременно указывать и вознаграждение, и связанную привычку запрещено.

#### Валидация:

Нельзя указывать одновременно вознаграждение и связанную привычку
В связанные привычки можно добавлять только приятные
У приятной привычки не может быть вознаграждения или связи
Время выполнения ≤ 120 секунд
Периодичность — не реже 1 раза в 7 дней

#### Пагинация:

Список привычек выводится с пагинацией — по 5 привычек на страницу.

#### Права доступа

Пользователь управляет только своими привычками (CRUD)
Публичные привычки доступны для просмотра всем пользователям
Редактирование и удаление чужих привычек запрещено

#### Эндпоинты

- Регистрация
- Авторизация (JWT)
- Список привычек пользователя (HabitViewSet — полный CRUD только для авторизованного пользователя.)
- Список публичных привычек (PublicHabitListAPIView — список привычек с is_public=True, доступен всем (AllowAny)
- Создание привычки
- Обновление привычки
- Удаление привычки

#### Напоминания

Реализована интеграция с Telegram:
- Celery Beat проверяет привычки каждую минуту
- При совпадении времени отправляется задача в очередь
- Celery Worker отправляет уведомление через Telegram Bot API

## Установка и настройка:

### Клонируйте репозиторий:

```
https://github.com/hristyaa/DRFHabitTracker.git
```

### Создайте виртуальное окружение и установите необходимые зависимости из `pyproject.toml`:

Выполните команду:

```
poetry install
```
Основные зависимости проекта:
- Django 5.2
- Django REST Framework
- SimpleJWT (JWT-аутентификация)
- PostgreSQL (psycopg2-binary)
- Pillow (работа с изображениями)
- Celery
- Redis
- django-celery-beat
- django-cors-headers
- drf-yasg (Swagger)
- requests (для Telegram API)

### Настройка переменных окружения

Скопируйте файл `.env.example` и переименуйте его в `.env`
Откройте `.env` и заполните ваши данные.

### Применение миграций
```
python manage.py migrate
```

### Запуск Redis
```
redis-server
```

### Запуск локального сервера
```
python manage.py runserver
```
После запуска сервера приложение будет доступно по адресу: `http://127.0.0.1:8000/`
### Запуск Celery Worker (в отдельном терминале)
```
celery -A config worker -l info
```
Для Windows используется -P eventlet.

### Запуск Celery Beat (в отдельном терминале)
```
celery -A config beat -l info
```
### Документация API

Swagger доступен по адресу:
`http://127.0.0.1:8000/swagger/`

## Тестирование:

python manage.py test
```

`coverage`.

```
coverage run --source='.' manage.py test

coverage report
